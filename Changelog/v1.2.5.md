# Changelog v1.2.5

### Changed

#### Enterprise Edition

- Refactored API token management in Settings, including permission scopes, expiration dates, and revocation. Newly created token secrets are shown only once, and token permissions cannot exceed the user's role.
- Refactored project webhook management for report events, with event selection, optional signing secrets, pause and resume controls, test deliveries, and recent delivery results.
- Refactored licensed project selection and usage counts. Projects outside the license allowance remain read-only, with their reports and files preserved. Project creation and report submission enforce the selected project allowance.
- Refactored manual license synchronization and automatic refresh of signed licenses to apply renewals and changes to the project allowance without entering a replacement key.
- License activation now requires acceptance of the current Enterprise License Agreement and records the acceptance. The Admin Console displays Enterprise license status, and removing a license requires typing `license` to confirm.
- Refactored white-label controls for Admin Console and email footer branding, custom copyright text, and the widget's “Powered by BugPin” attribution. Outgoing emails also use the configured application logo.

### Fixes

- Screenshots now preserve scrollbar visibility and content layout, including pages that hide scrollbars or use overlay scrollbars.
- Files migrated to Enterprise S3 storage can now be read and deleted through the configured storage provider. Migration streams file uploads, preserves local copies when a transfer or database update fails, and refreshes storage statistics when it finishes or pauses.
- Saving Enterprise email templates preserves edits in other languages. Notifications use the template for the recipient's language instead of replacing it with a custom English template when a localized default exists.
- SMTP delivery now reports full and partial recipient failures. Webhook test deliveries and report events use consistent signatures and request deadlines, and report deliveries respect project license access.
- Invalid replacement logo and favicon uploads preserve the existing branding assets. White-label preferences persist and apply consistently to the Admin Console, widget, and email notifications.
- Settings updates validate nested values and preserve existing fields that were not included in the update.
- Standardized Admin Console scrollbars with theme-aware scroll areas across pages, the sidebar, dialogs, tables, and lists.
- Styled native scrollbars in text editors, email previews, and the reporting widget to match light and dark themes, removing bright scrollbar tracks in dark mode.
- Restored optional Enterprise Edition verification scripts used by `make test` and `make typecheck`.

### Maintenance

- Widget tests no longer depend on the order in which test files run. Tests now reset the widget language, clear timers and buffered reports left by other test files, and use a shared setup for Preact's render scheduling.
- Docker publishing now runs Community and Enterprise Edition type checks and tests before building and publishing images. Refactored Enterprise type checks and isolated test setup.
